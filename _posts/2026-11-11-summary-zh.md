## [DeepMind 的 AlphaProof Code 验证 Signal 协议，引发争议](https://deepmind.google/blog/introducing-alphaproof-code/) ⭐️ 8.0/10

Google DeepMind 推出了 AlphaProof Code，这是一个多智能体 AI 框架，利用 Lean 等证明助手对软件进行形式化验证，并已应用于在机器码层面证明 libsignal（Signal 协议的参考实现）的关键安全属性。公告声称在已验证的库中未发现任何 bug，这一结果引发了社区的质疑。 这标志着 AI 驱动的形式化验证取得了重大进展，有望将数学上严谨的正确性证明更广泛地应用于现实世界的生产软件。如果能够规模化，它可能会从根本上改变消息协议和密码学库等关键系统的验证方式，从测试转向保证某些 bug 的绝对不存在。 该框架使用多个 AI 智能体将实际代码转换为有效的 Lean 定理和证明，并且在机器码层面而非源代码层面运行。然而，社区指出验证仅检查实现是否符合规范，而不检查规范本身的正确性，并且有人担心定理是否涵盖了所有相关属性。

hackernews · ilreb · 11月10日 12:11 · [社区讨论](https://news.ycombinator.com/item?id=50439193)

**背景**: 形式化验证使用数学逻辑来证明系统满足形式化规范，这与测试不同，测试只能采样输入，无法证明不存在 bug。Lean 是一个开源的证明助手和编程语言，支持编写机器可检查的证明，并已被用于验证前沿数学。AlphaProof Code 在此基础上，利用 AI 智能体自动为软件创建 Lean 证明，这是一项传统上劳动密集型的任务。

## [Chrome 联合多方推出指南，引导编码代理使用现代 Web 原语](https://github.com/GoogleChrome/modern-web-guidance) ⭐️ 8.0/10

Google Chrome 与 Firefox、MDN 和 Edge 合作，发布了“modern-web-guidance”1.0 版本，包含 200 多篇精选指南（约 1.7MB），旨在引导编码代理使用原生 Web 平台特性，而不是过时的 JavaScript 和基于 div 的模式。该项目以代理技能和 CLI 形式分发，内置 RAG 搜索引擎以及一个基于 3 万个 GitHub 仓库训练的确定性“legacy-scan”工具。 编码代理常常默认使用 div+JS 弹窗等遗留模式，即使现代原生 API 已经存在，因此这份跨厂商指南有望显著提升 AI 生成前端代码的质量和可访问性。Firefox、MDN 和 Edge 的参与体现了多浏览器在最佳实践上罕见的共识，但批评者担心这可能会巩固 Chrome 对 Web 标准的影响力。 该包包含一个 RAG 搜索，以约 7MB 的纯 JS 包在 CPU 上运行约 10ms（从 500MB 的原生栈缩减而来），legacy-scan 工具在留出仓库上达到 92% 的平均精确率。在 200 个任务、约 1,700 条 Playwright/AST 断言的评估中，代理的通过率从无引导时的 55% 提升到有引导时的 92%。

hackernews · paulirish · 11月10日 18:01 · [社区讨论](https://news.ycombinator.com/item?id=50443812)

**背景**: 现代浏览器现在原生支持许多以前需要 JavaScript 库或自定义代码的功能，例如用于在不包裹 span 的情况下为文本范围设置样式的 CSS Custom Highlight API、用于可访问模态框的 <dialog> 元素及 showModal()，以及用于自动增长文本区域的 field-sizing CSS 属性。然而，基于较旧代码训练的大型语言模型往往不会使用这些原生解决方案，而是默认采用熟悉的 div+JS 模式。该项目旨在通过提供由专家编写、可供代理检索和应用的精选指南来弥合这一知识差距。
