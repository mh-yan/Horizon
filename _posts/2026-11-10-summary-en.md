## [Show HN: Browser tool finds every satellite pass over any place in the last week and shows its photos](https://www.watched.earth/) ⭐️ 8.0/10

A developer launched 'watched.earth', a browser-based tool that uses SGP4 propagation on the CelesTrak catalog to find all satellite passes over any location in the last 7 days, then retrieves actual Sentinel-2, Landsat, and NASA imagery from those passes. The tool runs the pass search in about half a second and renders all ~17k tracked objects on the GPU by solving Kepler's equation every frame. This tool makes satellite imagery accessible to non-experts by directly linking passes to actual photos, which is valuable for geospatial professionals, backpackers, and anyone curious about what has photographed their area. It demonstrates how complex orbital mechanics can be efficiently implemented in the browser, potentially inspiring more interactive geospatial applications. The pass search was validated against brute force on poles, the antimeridian, and tiny swaths with zero missed passes, and the developer noted that Sentinel-2 timestamps are often 5-10 minutes off from actual overpass time. The tool only labels a location as 'watched' if a real image exists and does not store user location.

hackernews · a585gupt · Nov 9, 17:51 · [Discussion](https://news.ycombinator.com/item?id=50428907)

**Background**: SGP4 is a widely used mathematical model for propagating satellite orbits from Two-Line Element (TLE) sets, accounting for perturbations like atmospheric drag and Earth's oblateness. CelesTrak is a public catalog that provides TLE data for thousands of satellites. Sentinel-2 is a European Space Agency mission that captures high-resolution multispectral imagery of land and coastal areas, often used for environmental monitoring.

## [E-means: Outperforming k-means in one-tenth the epochs](https://e-means.github.io/) ⭐️ 7.0/10

A new clustering algorithm called E-means has been introduced, which uses an exponential moving average optimization procedure with mini-batch updates to outperform Lloyd's k-means algorithm while requiring only one-tenth the number of epochs. The method leverages modern deep learning machinery and new insights to achieve faster convergence. E-means could significantly speed up clustering tasks, which are fundamental in data analysis, retrieval, quantization, and data curation. Its potential integration into widely used libraries like scipy could make it more accessible than existing GPU-accelerated alternatives such as Facebook's faiss. The algorithm maintains the centroid within the convex hull through its update rule, and community members have reported a 146x speedup on GPU when adapted to an IVF index. However, a user found it less effective for relaxing an icosahedral mesh on a sphere, indicating that benefits depend on the use case.

hackernews · porridgeraisin · Nov 9, 18:45 · [Discussion](https://news.ycombinator.com/item?id=50429734)

**Background**: K-means clustering is a widely used method that partitions data into k clusters by minimizing within-cluster variances, typically solved with Lloyd's algorithm. E-means introduces an exponential moving average optimization with mini-batch updates, inspired by deep learning techniques, to converge faster. The number of epochs refers to complete passes over the dataset, so fewer epochs mean faster training.
