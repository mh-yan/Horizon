## [Porting a 1993 Amiga Game to Godot with LLM Reading 68000 Assembly](https://babyloniantwins.com/blog/porting-a-1993-amiga-game-to-godot/) ⭐️ 8.0/10

A developer successfully ported his 1993 Amiga game, originally written in MC68000 assembly, to the Godot engine using an LLM (Claude) to read and translate the assembly code. The port achieved byte-identical binaries when reassembled with vasm and resulted in a playable game within an evening. This demonstrates a novel and powerful use of LLMs for retrocomputing and game preservation, potentially lowering the barrier for porting legacy assembly code to modern engines. It could inspire similar projects and highlight the value of AI in understanding and translating low-level code. The developer used Claude (referred to as 'Claude Fable 5') during a holiday, and the model assembled the code using vasm on a Mac until the binary was byte-identical to the original. A 108-byte mismatch was traced to the original game being saved as a memory snapshot after running, not clean assembler output.

**Background**: The Amiga was a popular personal computer in the late 1980s and early 1990s, and many games were written in MC68000 assembly for performance. AsmOne was a popular assembler for the Amiga that assembled code into memory, allowing games to save memory snapshots. vasm is a modern portable assembler that can target the 68000 CPU and produce byte-identical binaries when given the correct source.
